# Biggie

**Biggie** is a Windows desktop utility by Room06Tech for finding large files and quickly locating them on your computer.

## Features

- **Large Files:** Scan a selected directory and find its largest files and folders.
- **Locate File:** Open a file's location in Windows File Explorer.

## Installation

Download the latest Windows installer from the [GitHub Releases](https://github.com/ashford232/biggie/releases) page and follow the installation instructions.

## Development

Biggie is built with:

- Flutter
- Dart

To run the project locally:

```bash
flutter pub get
flutter run -d windows
```
